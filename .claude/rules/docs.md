docs/ の文書は、人間と決めたことの記録として、設計や issue を判断するときに読まれる。

- 人間の発言や回答をもとに書くときは、その人の言葉に近い言い方で書く。言い換えで意味を強めたり、挙がった案を二択にまとめたりすると、言っていないことが決まったこととして残る
- 決まっていないことは「まだ決めていない」と書き、推測で埋めない。案を書くときは、案だと分かる書き方にする（言い切りの文は、後で読むエージェントには決定に見える）
- 文を書いたり書き換えたりしたら（誤字やリンクだけの修正は除く）、`/remove-ai-tells` で検出をかけてから人間に出す。AI が書いたように読める文章は、読み手に中身を割り引かれる
