docs/ の文書は、設計や issue を判断するときの基準として読まれる。書いてあることは、決まったこととして扱われる。

人間と話して決めたことは、なるべくその人の言葉で書く。言い換えたときは、意味が強まっていないか、挙がった案を二択に狭めていないかを確かめる。まだ決めていないことは推測で埋めずに「まだ決めていない」と書き、案は案と分かるように書く。

書き終えたら `/remove-ai-tells` をかけ、直してから人間に見せる。AI が書いたように読める文章だと、読む人は中身まで疑う。誤字やリンクだけの修正ではかけなくてよい。
