この repo は公開している。repo のファイルと GitHub 上のもの（issue・PR・コメント・コミットメッセージ・ブランチ名・PR に貼る画像）は誰でも読める。後から消すには履歴の書き換えが要り、それでもフォークやキャッシュには残ることがある。

ここに書くのはプロダクトを作るのに必要で、公開して困らない情報だけにする。会話・Claude の memory・非公開のドキュメント・チャットから持ち込んだ文脈は、そのまま写さない。判断の理由が特定の人の事情なら、プロダクト上の理由に言い直す（「既存サービスと重なる」など）。言い直して意味が残らないなら書かない。

書かないもの:

- repo の持ち主以外の、特定できる人や会社の話（名前、発言、持ち主との関係、公開されていない事業や計画）
- repo の持ち主の私的な事情（勤め先、お金、健康、住んでいる場所、予定、人間関係）
- 人を特定できるデータ（メールアドレス、電話番号、顔、位置情報）。写真をコミットするときや PR に貼るときは、位置情報などのメタデータと写り込みも確かめる
- 秘密の値と、非公開のドキュメントやチャットへのリンク

書いてよいか迷ったら書かない。確認や報告は、ローカルの会話やクラウドの run の最終報告のように、公開されない場で行う。issue や PR のコメントには、何が私的なのかを種類も含めて書かない。種類（位置情報、住所など）だけでも、公開されているもののどこを見ればよいかを教えることになるため。コメントが要るときは「確認したいことがあるので run の報告を見てほしい」のように、中身を含めずに書く。

push 済みのものや issue の添付に見つけたときは、自分で消して済ませず、公開されない場で人間に場所を伝える。新しいコミットで消しても履歴に残り、秘密の値なら無効化も要るため。
