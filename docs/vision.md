# Vision

投稿が流れて消えず、積み上がっていく SNS を作る。

Instagram などでは、投稿はタイムラインを過ぎると消費されて終わる。SNS はインフルエンサーのものになり、普通の人の投稿は埋もれている。

このサービスでは、投稿の価値が後から増えていく。世界中の普通の人の普通の日常が、言語の壁を越えて一箇所に積み上がる。撮ったものを AI が認識し、そこに人が注釈を重ねる。その注釈で次の認識が賢くなる。アニメ「東のエデン」のエデンシステムから着想した。

フォロワー数やいいね数、ランキングでは競わせない。投稿が誰かの役に立ったときは、それを本人に知らせる。

世界と繋がらないとサービスの意味がないので、端末の中だけで完結する MVP は作らない。

## 前提

- 一人で運営する
- 在庫や物流を持たない
- スモールビジネスで終わらせない
- 認識はオンデバイスを基本にする。クラウドの大型モデルや外部 DB を多用する構成はコストが合わないので取らない

## まだ決めていないこと

どんな切り口で集めるかは決めていない。「今日の〜」（of today）もあれば、「人生で一番の〜」（of life）もありうる。後者なら、いろんな人の best dinner が分かる。

最初に扱うカテゴリも決めていない。
