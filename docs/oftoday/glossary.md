# 用語集

oftoday で使う言葉と、コードでの名前をそろえるための文書。「用語」の表にあるのは [vision.md](vision.md) で意味が決まっている語で、コードでの名前はまだ決めていない。意味も決まっていない語は「まだ決めていないこと」に候補として置く。

## 用語

| 用語 | コードでの名前 | 意味 |
| --- | --- | --- |
| 投稿 | 未定（「投稿の名前」） | SNS に載せるもの。流れて消えず、後から価値が増えていく |
| 認識 | 未定 | 撮ったものを AI が読み取ること |
| 注釈 | 未定（「人が足すものの呼び方」） | 認識の上に人が重ねるもの。注釈で次の認識が賢くなる |
| 切り口 | 未定（「切り口とお題」） | 投稿をどんな括りで集めるか |

## まだ決めていないこと

### 投稿の名前

「記録」や `Observation` と呼ぶこともある。`Observation` は、`@Observable` を使うモジュールでは型名に使えない（Observation モジュールの型と衝突してコンパイルエラーになる）。Vision の `RecognizedTextObservation` などとも紛れる。

- 案 A: 日本語は「投稿」、コードは `Post` にそろえ、「記録」は使わない。vision.md と同じ語で、主な Apple のフレームワークに同じ名前の型は無い
- 案 B: 公開する行為を「投稿」、積み上がるデータを「記録」（`Record`）と分ける。行為とデータを別の語で呼べる。ただし vision.md はデータの意味で「投稿」を使っているので、採るなら vision.md の文を変える必要がある。`Record` は Combine の型と同じ名前

### 特徴の名前

撮った対象について、カテゴリごとに決まった項目とその値を何と呼ぶか。

- 案 A: 日本語は「特徴」、コードは `TraitValue`・`TraitDefinition` のように後ろに語を付ける。単体の `Trait` は Swift Testing の `Trait` と同じ名前になり、`import Testing` したテストではモジュール名を付けて書く必要がある
- 案 B: 日本語を「属性」に変え、コードは `Attribute` にする。SwiftData の `@Attribute` マクロと紛れる

### カテゴリ

vision.md には「最初に扱うカテゴリも決めていない」とだけある。撮る対象の種類という意味で使う案がある。カテゴリごとの特徴の一覧（`CategoryDefinition`）を、コードでなくデータとして持つ案もある。

### 人が足すものの呼び方

人が足すものには、特徴の値を直すこと、ほかの人の値を正しいと認めること（確認）、感想を書くことがありうる。値ごとに、何が埋めたか（出どころ、`Source`）と、人がどう関わったか（`HumanAction`）を持つ案もある。

- 案 A: 全部を「注釈」と呼び、修正・確認・感想はその種類とする。vision.md の「人が注釈を重ね、その注釈で次の認識が賢くなる」とそのまま合う
- 案 B: 「注釈」は感想のような文章だけを指し、修正と確認は別の語にする。採るなら、vision.md の「その注釈で次の認識が賢くなる」を変える必要がある

コードでの名前を決めるときに紛れるものとして、`Annotation` は MapKit の SwiftUI の型と、`Confirmation` は Swift Testing の型と同じ名前になる。

### 辞書の名前

撮った対象ごとに、みんなで育てる情報を何と呼ぶか。Swift 標準の `Dictionary` と紛れるので、コードでは別の名前が要る。

- 案 A: 日本語は「辞書」、コードは `Catalog`。日本語とコードで名前がずれる
- 案 B: 日本語も「カタログ」にそろえる。そろうが、何を集めたものかが日本語から読み取りにくい

### 切り口とお題

切り口は vision.md でもまだ決めていない。世界中の人が同じ日に撮る対象を「お題」と呼ぶ案があり、切り口との関係も決まっていない。案はまだ無い。コードでの名前を決めるときは、`Prompt` が FoundationModels の型と同じ名前になり、`Theme` は UI のテーマと紛れる。

### そのほかの候補

写真（`Photo`）と画像ベクトル（`ImageEmbedding`。Vision では feature print と呼んでいる）。今のところ、ほかの名前と食い違う点は見つかっていない。

### サービス名

まだ決めていない。docs と repo では oftoday と呼んでいる。
